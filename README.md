## 🚀 Project Overview

This project uses Machine Learning to estimate medical insurance costs using features such as:

- Age
- Sex
- BMI
- Children
- Smoker
- Region

The project includes:

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Hyperparameter Tuning
- Model Evaluation
- Streamlit Web Application
